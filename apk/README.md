## 🚀 Guía de Instalación Rápida

1. Descarga el archivo `app-debug.apk` directamente en tu smartphone.
2. Al pulsar sobre la descarga finalizada, si el sistema te pregunta por seguridad, selecciona **Ajustes** -> **Permitir desde esta fuente**.
3. Presiona **Instalar**.
4. ¡Listo! Abre la aplicación e ingresa tus credenciales privadas.

## ⚙️ Detalles Técnicos del APK

- **Nombre del Paquete**: `com.example.taskdashboard`
